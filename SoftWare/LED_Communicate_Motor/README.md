# 无人机飞行控制系统

基于 STM32F103 的四旋翼无人机飞行控制系统，支持姿态自稳、气压计定高、无线遥控等功能。

## 功能特性

### 核心功能
- ✅ **姿态自稳飞行**：MPU6050 六轴传感器，四元数姿态解算
- ✅ **气压计定高**：SPL06-001 高精度气压计，±0.5m 精度
- ✅ **无线遥控**：nRF24L01 2.4GHz，ANO_DT 协议，32 字节数据
- ✅ **LED 状态指示**：连接状态、飞行状态可视化
- ✅ **电机控制**：PWM 输出，支持好盈天行者电调

### 飞行模式
| 模式 | 说明 | 进入条件 |
|------|------|----------|
| **IDLE** | 怠速/未解锁 | 上电默认 |
| **NORMAL** | 姿态自稳 | 解锁成功 |
| **FIX_HEIGHT** | 定高模式 | AUX1 > 1500 |
| **FAIL** | 失控保护 | 遥控器失联 |

### 解锁流程 (日本手 Mode 1)
```
1. 油门推到最大 (≥1900) 保持 1 秒
2. 油门拉到最小 (≤1100) 保持 1 秒
3. 解锁完成，电机怠速旋转
```

## 硬件配置

### 主控板
- **MCU**: STM32F103C8T6 (72MHz, 64KB Flash, 20KB RAM)
- **开发环境**: STM32CubeMX + CMake + GCC

### 传感器
| 传感器 | 型号 | 接口 | 说明 |
|--------|------|------|------|
| **IMU** | MPU6050 | I2C1 (PB6/PB7) | 6 轴陀螺仪 + 加速度计 |
| **气压计** | SPL06-001 | I2C2 (PB10/PB11) | 高精度气压/温度 |

### 无线通讯
| 模块 | 型号 | 接口 | 说明 |
|------|------|------|------|
| **接收机** | nRF24L01 | SPI1 | 2.4GHz 无线接收 |

**nRF24L01 配置**:
```c
频道：CHANNEL = 0
地址：{0xAA, 0xBB, 0xCC, 0x00, 0x01}
数据速率：2Mbps
发射功率：0dBm
载荷宽度：32 字节
```

### 电机布局 (X 型四旋翼)
```
       前 (Front)
        ↑
   M1      M3
  (CCW)   (CW)
     \  /
      \/
      /\
     /  \
  M2      M4
  (CW)   (CCW)

M1: 左上前  TIM3_CH1  (PA6)
M2: 左下前  TIM4_CH4  (PB9)
M3: 右上前  TIM2_CH2  (PA1)
M4: 右下前  TIM1_CH3  (PA8)
```

### LED 指示
| LED | 状态 | 说明 |
|-----|------|------|
| LED1/2 (前) | 常亮 | 遥控器连接成功 |
| LED1/2 (前) | 熄灭 | 遥控器失联 |
| LED3/4 (后) | 慢闪 (500ms) | IDLE 状态 |
| LED3/4 (后) | 快闪 (200ms) | NORMAL 飞行 |
| LED3/4 (后) | 常亮 | FIX_HEIGHT 定高 |
| LED3/4 (后) | 熄灭 | FAIL 故障 |

│   6ms/3p    │   6ms/2p    │  100ms/1p   │   24ms/2p    │

## 通讯协议

### ANO_DT 协议格式

**接收帧 (遥控器 → 飞控)**:
```
┌────┬────┬────┬────┬──────────┬─────┐
│0xAA│0xAF│0x03│LEN │   DATA   │ SUM │
└────┴────┴────┴────┴──────────┴─────┘
 1B   1B   1B   1B    20B       1B
```

**数据区定义**:
| 偏移 | 字段 | 长度 | 说明 | 范围 |
|------|------|------|------|------|
| 4-5 | THR | 2B | 油门 (右摇杆上下) | 1000-2000 |
| 6-7 | YAW | 2B | 偏航 (右摇杆左右) | 1000-2000 |
| 8-9 | ROL | 2B | 横滚 (左摇杆左右) | 1000-2000 |
| 10-11 | PIT | 2B | 俯仰 (左摇杆上下) | 1000-2000 |
| 12-13 | AUX1 | 2B | 辅助 1 (定高开关) | 1000-2000 |
| 14-15 | AUX2 | 2B | 辅助 2 | 1000-2000 |

**回复帧 (飞控 → 遥控器)**:
```
┌────┬────┬────┬────┬────┬────┬────┬────┬────┐
│0xAA│0xAF│0x05│0x08│Volt│Volt│ HW │ SW │SUM │
└────┴────┴────┴────┴────┴────┴────┴────┴────┘
```

### 通道映射 (日本手 Mode 1)
```
左摇杆：左右 = ROL (横滚), 上下 = PIT (俯仰)
右摇杆：左右 = YAW (偏航), 上下 = THR (油门)

中立值：1500
最小值：1000
最大值：2000
```

## 快速开始

### 1. 编译项目
```bash
cd build
cmake .. -G "Ninja"
ninja
```

### 2. 烧录固件
使用 ST-Link 或 J-Link 烧录 `build/log.elf` 到 STM32F103。

### 3. 首次上电
1. 连接电池，观察 LED 状态
2. 打开遥控器，等待 LED1/2 常亮 (连接成功)
3. 执行解锁流程 (油门最大 1 秒 → 最小 1 秒)
4. 电机怠速旋转表示解锁成功

### 4. 调试输出
通过 UART2 (PA2/PA3) 输出调试信息，波特率 115200：
```
Flight task started
COM task started
Baro task started
Flight: UNLOCKED
Flight: FIX_HEIGHT, alt=12 m
```

## PID 调参

### 默认参数
```c
// 俯仰角 (外环角度，内环角速度)
pitch_pid = {.kp=-7.0, .ki=0.0, .kd=0.0}
gyro_y_pid = {.kp=3.0, .ki=0.0, .kd=0.5}

// 横滚角
roll_pid = {.kp=-7.0, .ki=0.0, .kd=0.0}
gyro_x_pid = {.kp=3.0, .ki=0.0, .kd=0.5}

// 偏航角
yaw_pid = {.kp=-3.0, .ki=0.0, .kd=0.0}
gyro_z_pid = {.kp=-5.0, .ki=0.0, .kd=0.0}

// 定高 (气压计)
height_pid = {.kp=-0.6, .ki=0.0, .kd=-0.2}
```

### 调参步骤
1. **先调内环 (角速度)**: 增大 KP 直到响应快速但略有超调，增加 KD 抑制超调
2. **再调外环 (角度)**: 增大 KP 使角度跟踪准确
3. **最后调定高**: 气压计噪声较大，KP 不宜过大

### 调参技巧
| 现象 | 原因 | 解决方法 |
|------|------|----------|
| 飞机抖动 | KD 太小 | 增大 KD |
| 响应慢 | KP 太小 | 增大 KP |
| 超调大 | KP 太大 | 减小 KP |
| 漂移 | KI 太小 | 适当增加 KI |

## 故障排除

### 无法连接遥控器
1. 检查 nRF24L01 接线 (SPI + CE + CSN)
2. 确认频道一致 (CHANNEL = 0)
3. 检查地址配置是否与遥控器匹配
4. 查看调试输出确认接收状态

### 电机不转
1. 检查电调供电 (5V/12V)
2. 确认 PWM 引脚连接正确
3. 执行电调校准流程
4. 检查解锁状态 (LED3/4 快闪表示已解锁)

### 姿态解算异常
1. 检查 MPU6050 I2C 通信
2. 确认传感器安装方向
3. 校准加速度计零偏

### 定高不准确
1. 检查 SPL06-001 I2C 通信
2. 确认气压计通风良好
3. 校准海平面气压基准
