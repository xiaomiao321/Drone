# nRF24L01 无线通讯协议文档

## 1. 硬件配置

### 1.1 无线模块
- **型号**: nRF24L01 (2.4GHz)
- **接口**: SPI
- **工作模式**: 双向通讯（接收端 RX / 发射端 TX）

### 1.2 地址配置
```c
// 5 字节发送/接收地址（必须与遥控器一致）
uint8_t TX_ADDRESS[5] = {0xAA, 0xBB, 0xCC, 0x00, 0x01};
```

### 1.3 射频参数
| 参数 | 配置值 | 说明 |
|------|--------|------|
| 工作频道 | CHANNEL = 0 | 0-125，与遥控器一致 |
| 数据速率 | 2Mbps | 高速模式 |
| 发射功率 | 0dBm | 标准功率 |
| 有效载荷宽度 | 32 字节 | 固定长度 |
| CRC 校验 | 16 位 | 增强可靠性 |
| 自动重发 | 250us+86us, 10 次 | 增强可靠性 |

### 1.4 特殊寄存器配置
```c
// 接收端 RX 模式特殊配置（匹配遥控器 TX2 模式）
SPI_RW(0x50);                    // 选择寄存器组
SPI_RW(0x73);
Int_nRF24L01_Write_Reg(0x1C, 0x01);  // 兼容模式配置
Int_nRF24L01_Write_Reg(0x1D, 0x06);  // 兼容模式配置
```

## 2. ANO_DT 通讯协议

### 2.1 数据帧格式

```
┌────────┬────────┬────────┬────────┬──────────┬─────────┐
│ 帧头 1  │ 帧头 2  │ 功能字  │ 数据长度│  数据区   │  校验和  │
│ 0xAA   │ 0xAF   │ 0x03   │  0x14  │ 20 字节   │  1 字节  │
└────────┴────────┴────────┴────────┴──────────┴─────────┘
   1 字节   1 字节   1 字节   1 字节   20 字节     1 字节
```

**总帧长度**: 25 字节

### 2.2 数据区详细定义（遥控器 → 接收端）

| 字节偏移 | 字段 | 长度 | 说明 | 数据范围 |
|----------|------|------|------|----------|
| 0-1 | 帧头 | 2 字节 | `0xAA 0xAF` | 固定 |
| 2 | 功能字 | 1 字节 | `0x03` = RC 遥控数据 | 固定 |
| 3 | 数据长度 | 1 字节 | `0x14` = 20 字节 | 固定 |
| 4-5 | THR | 2 字节 | **油门** (右摇杆上下) | 1000-2000 |
| 6-7 | YAW | 2 字节 | **偏航** (右摇杆左右) | 1000-2000 |
| 8-9 | ROL | 2 字节 | **横滚** (左摇杆左右) | 1000-2000 |
| 10-11 | PIT | 2 字节 | **俯仰** (左摇杆上下) | 1000-2000 |
| 12-13 | AUX1 | 2 字节 | 辅助通道 1 | 1000-2000 |
| 14-15 | AUX2 | 2 字节 | 辅助通道 2 | 1000-2000 |
| 16-17 | AUX3 | 2 字节 | 辅助通道 3 | 1000-2000 |
| 18-19 | AUX4 | 2 字节 | 辅助通道 4 | 1000-2000 |
| 20 | 功能字 | 1 字节 | `0x05` = 飞控状态 | 固定 |
| 21-22 | Voltage | 2 字节 | 电池电压 | - |
| 23 | Hardware | 1 字节 | 硬件类型 | 1=四轴，2=万向轮 |
| 24 | SUM | 1 字节 | 校验和 | - |

**注意**: 多字节数据采用 **大端模式** (高字节在前)

### 2.3 通道值定义

| 通道值 | 含义 |
|--------|------|
| 1000 | 最小值/最左/最下 |
| 1500 | 中立位置 |
| 2000 | 最大值/最右/最上 |

### 2.4 遥控器通道映射（实测）

```
┌─────────────────────────────────────────────────────────┐
│                    遥控器布局 (Mode 1/日本手)              │
│                                                         │
│         ┌─────────────┐         ┌─────────────┐         │
│         │    PIT ↑    │         │    THR ↑    │         │
│         │             │         │             │         │
│    ROL ←│             │→ ROL   │             │← YAW    │
│         │             │         │             │         │
│         │    PIT ↓    │         │    THR ↓    │         │
│         └─────────────┘         └─────────────┘         │
│            左摇杆                      右摇杆             │
│                                                         │
│  左摇杆左右 → ROL (横滚)   字节 8-9                      │
│  左摇杆上下 → PIT (俯仰)   字节 10-11                    │
│  右摇杆左右 → YAW (偏航)   字节 6-7                      │
│  右摇杆上下 → THR (油门)   字节 4-5                      │
└─────────────────────────────────────────────────────────┘
```

### 2.5 校验和计算

```c
uint8_t sum = 0;
for (uint8_t i = 0; i < 24; i++) {  // 帧头到数据区末尾
    sum += data[i];
}
// sum 应该等于 data[24]
```

## 4. 软件接口

### 4.1 数据结构定义
```c
typedef struct {
    uint16_t thr;   // 油门 (右摇杆上下)
    uint16_t yaw;   // 偏航 (右摇杆左右)
    uint16_t rol;   // 横滚 (左摇杆左右)
    uint16_t pit;   // 俯仰 (左摇杆上下)
    uint16_t aux1;  // 辅助通道 1
    uint16_t aux2;  // 辅助通道 2
    uint16_t aux3;  // 辅助通道 3
    uint16_t aux4;  // 辅助通道 4
} RC_Data_t;
```

### 4.2 解析函数
```c
uint8_t ANO_DT_ParseRC(uint8_t *buf, uint8_t len, RC_Data_t *rc) {
    // 检查帧头
    if (buf[0] != 0xAA || buf[1] != 0xAF) return 0;
    // 检查功能字
    if (buf[2] != 0x03) return 0;
    // 检查数据长度
    uint8_t data_len = buf[3];
    if (data_len < 12) return 0;
    // 总帧长度 = 4 字节头 + 数据区 + 1 字节校验和
    uint8_t frame_len = 4 + data_len + 1;
    if (frame_len > len) return 0;
    // 校验和验证
    uint8_t sum = 0;
    for (uint8_t i = 0; i < frame_len - 1; i++) sum += buf[i];
    if (sum != buf[frame_len - 1]) return 0;
    // 解析通道数据 (大端模式)
    rc->thr  = (uint16_t)((buf[4] << 8) | buf[5]);
    rc->yaw  = (uint16_t)((buf[6] << 8) | buf[7]);
    rc->rol  = (uint16_t)((buf[8] << 8) | buf[9]);
    rc->pit  = (uint16_t)((buf[10] << 8) | buf[11]);
    rc->aux1 = (uint16_t)((buf[12] << 8) | buf[13]);
    rc->aux2 = (uint16_t)((buf[14] << 8) | buf[15]);
    return 1;
}
```

### 4.3 使用示例
```c
RC_Data_t rc_data = {0};
uint8_t com_data[32] = {0};

// 接收数据
if (Int_nRF24L01_RxPacket(com_data) == 0) {
    // 解析 RC 数据

                     rc_data.thr, rc_data.yaw, rc_data.rol, rc_data.pit);
        // 在此处处理遥控数据...
    }
}
```

## 5. 常见问题

### 5.1 无法接收数据
1. 检查频道是否一致（CHANNEL = 0）
2. 检查地址是否一致（TX_ADDRESS）
3. 检查特殊寄存器配置（0x50, 0x1C, 0x1D）
4. 检查 CE 引脚状态（接收时应为高电平）

### 5.2 数据解析失败
1. 检查校验和计算是否正确
2. 检查字节序（大端模式）
3. 检查帧头是否正确（0xAA 0xAF）
4. 检查功能字是否正确（0x03）

### 5.3 通道值异常
1. 中立值应为 1500 (0x05DC)
2. 最小值应为 1000 (0x03E8)
3. 最大值应为 2000 (0x07D0)
4. 如果值不对，检查遥控器校准
